# 🚇 SubwayBuilder Maps – Greater Kuala Lumpur & Pulau Pinang

This repository contains custom **SubwayBuilder save files** featuring conceptual integrated transit maps for:

- Greater Kuala Lumpur  
- Pulau Pinang  

These maps are **unofficial**, created for design and gameplay purposes, and **not drawn to real-world scale**.

---

## 📥 How to Use

1. **Download** the save file(s) from this repository  
2. Locate your SubwayBuilder save folder: Documents/SubwayBuilder/saves
3. **Move or copy** the downloaded file(s) into the folder above  
4. Launch **SubwayBuilder** and load the map from your saves  

---

## 📌 Notes

- These maps are **conceptual designs** and may not reflect real geography  
- Created for fun, experimentation, and transit design ideas  
- Works best with the latest version of SubwayBuilder
